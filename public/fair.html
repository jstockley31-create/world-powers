What this page proves — and what it can't

  • The code fingerprint is calculated by the server from its own files every time it starts. If a single character of the game rules changes, the fingerprint changes and a new entry appears under “Game updates” with the date and time.
  • Admin actions that affect the game — editing a nation, changing settings, rolling back the world, starting events, adding or removing AI — are written to this log automatically, with exactly what changed. There is no button to hide or delete entries.
  • Settings are shown live. Anything different from the standard rules is highlighted.
  • Every game action is checked by the server. Your browser only asks; the server applies the rules, so players can't edit their own money, troops or timers. Suspicious activity (like actions faster than a person can click) is flagged for review.
  • Honest limit: this is a transparency record kept by the game's server. The people who run the server could, in principle, change the server itself. The record makes that visible rather than impossible — any code change shows up as a new fingerprint and date.
